# c-learning

## 这是什么

从 2026 年 11 月开始，我把 C 语言学习过程中的练习代码提交到这里。

目的很简单：让学习过程留下痕迹。每学一个知识点就写一个程序、提交一次，时间久了能看出自己到底走到哪一步。

| `01-basics` | 基础语法：变量、分支、循环 | 进行中 |

## 怎么运行

需要 gcc（Windows 可用 MinGW-w64，Linux 通常自带）：

```bash
gcc 01-basics/hello.c -o hello
./hello
```

Windows 上产物是 `hello.exe`，直接用 `hello` 也能运行。
